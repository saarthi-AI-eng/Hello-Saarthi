## Logo Specifications

### Color Variants

**Primary Logo** (Full Color)
- Icon: Blue to Purple gradient
- Text: Dark gray (#1F2937) or Blue (#2563EB)
- Background: White

**Reversed Logo** (Dark backgrounds)
- Icon: White or light gradient
- Text: White
- Background: Dark (#111827)

**Monochrome**
- All Black (#000000) on light backgrounds
- All White (#FFFFFF) on dark backgrounds

### Typography

**Primary Font:** Inter (Google Fonts)
- Weight: Medium (500) or Semibold (600)
- Character: Modern, professional, geometric
- Excellent readability at small sizes

**Alternative Fonts:**
- Outfit (Rounded, friendly)
- Poppins (Geometric, clean)
- Space Grotesk (Tech-forward)

**Text Style:**
- "Saarthi" - Main brand name
- ".ai" - Slightly smaller, or lighter weight, or different color

### Size Variations

1. **Full Logo** (Icon + Wordmark)
   - Usage: Website header, presentations, documents
   - Minimum width: 120px

2. **Icon Only**
   - Usage: App icon, favicon, social media profile
   - Sizes: 512x512px, 192x192px, 64x64px, 32x32px, 16x16px

3. **Wordmark Only**
   - Usage: When icon is already established
   - Minimum width: 80px

### Clear Space
- Maintain clear space around logo equal to the height of ".ai" in the wordmark
- No other elements should intrude into this space

## Implementation Steps

### Using Nano Banano (Google Gemini Image Generation)

1. **Access Nano Banano:**
   - Visit: https://gemini.google.com
   - Or use Google AI Studio

2. **Generate Logo Options:**
   - Copy each prompt above (Options 1-6)
   - Paste into Nano Banano
   - Generate multiple variations
   - Iterate with refinements

3. **Refinement Prompts:**
   If initial output needs adjustment:
   - "Make it more minimal"
   - "Adjust colors to #2563EB and #8B5CF6"
   - "Simplify the design, remove details"
   - "Make icon more circular for app icon"
   - "Increase contrast"

4. **Select Best Option:**
   - Review all generated options
   - Test at different sizes (large, small, favicon)
   - Check readability and recognition
   - Ensure it aligns with brand personality

5. **Finalize:**
   - Export as SVG (vector) if possible
   - Also export PNG at multiple resolutions
   - Create all color variants
   - Document brand guidelines

## Logo Usage Guidelines

### Do's ✅
- Use official logo files only
- Maintain minimum size requirements
- Ensure adequate clear space
- Use on approved backgrounds
- Maintain aspect ratio

### Don'ts ❌
- Don't stretch or distort
- Don't change colors arbitrarily
- Don't add effects (shadows, glows, 3D)
- Don't rotate or tilt
- Don't use low-resolution files
